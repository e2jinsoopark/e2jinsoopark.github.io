# 갈피 (GALPI)

**갈피**는 영어 논문 PDF를 올리면 **왼쪽에 원문, 오른쪽에 한국어 번역**을 나란히 보여 주는 개인용 논문 뷰어입니다.
책갈피처럼, 읽던 논문과 읽던 자리를 지켜 줍니다.
어느 쪽이든 문장에 마우스를 올리면 반대쪽의 짝 문장이 함께 표시됩니다.
GitHub Pages에서 바로 열리는 정적 웹앱이라 설치할 것이 없습니다.

**바로 열기: <https://e2jinsoopark.github.io/>** (가짜 AI로 둘러보기: <https://e2jinsoopark.github.io/?mock=1>)

## 주요 기능

| 기능 | 설명 |
|---|---|
| 문장 1:1 번역 | 문장 단위로 번역하고 원문↔번역 문장을 마우스 올림으로 서로 표시. 한 논문 안의 전문용어는 처음 고른 번역어로 통일(간호·중환자 용어집 내장), 영어 그대로 돌아온 문장은 ‘다시 시도’로 표시 |
| 번역 겹쳐보기 | PDF 레이아웃 위에 번역문을 덮어서 보기 |
| 라이브러리 | 폴더(하위 폴더 포함)별 정리, 검색, 즐겨찾기, 최근 읽음 |
| 기기 간 동기화 | 내 **비공개** GitHub 저장소에 논문·번역·메모를 저장 → 데스크톱·노트북 어디서나 같은 라이브러리 |
| 코드별 서재·전체 공용 서재 | 초대 코드마다 **그 코드를 가진 사람만 보는 서재**(‘<이름> 서재’)와, 초대받은 모두가 보는 **전체 공용 서재**. 폴더·논문·번역은 그 서재를 보는 사람끼리 공유, 하이라이트·메모·AI 기록은 나만. 휴지통(30일)·최근 활동 |
| 요약 | 연구 목적·방법·결과·한계·시사점 구조 요약 |
| AI 채팅 | 논문 내용에 근거한 질의응답, 근거 문장으로 바로 이동 |
| AI 설명 | 선택한 문장, 그림·표·수식 영역을 드래그해서 설명 |
| 스마트 인용 | 본문 인용 번호에 마우스를 올리면 참고문헌 정보 표시 |
| 미리보기 | Figure·Table·Section 링크를 누르지 않고 미리보기 |
| 핵심 밑줄 | 핵심 기여·방법·결과·한계 문장 자동 밑줄 |
| 하이라이트·메모 | 4색 하이라이트, 메모, 메모 모아보기 |
| 관련 논문 | PubMed 유사 논문 + Europe PMC 인용 수, 폴더 기준 추천 (키 필요 없음) |

## 처음 설정 (기기마다 한 번)

API 키와 GitHub 토큰은 **그 브라우저에만** 저장됩니다. 다른 기기에서는 한 번 더 입력해야 합니다.

### 1. AI 연결 (넷 중 하나)

**설정 → AI 번역**에서 고릅니다. 나중에 언제든 바꿀 수 있고, 바꿔도 다른 키·초대 코드는 지워지지 않습니다.

| 선택 | 필요한 것 | 키 만드는 곳 | 비용 |
|---|---|---|---|
| 키 없이 쓰기 (초대 코드) | 초대 링크 또는 코드 (`PR-XXXX-XXXX`, 또는 초대한 분이 정한 코드) | (초대한 분이 줌) | 초대한 분이 냄, 하루 한도 있음 |
| Claude | Anthropic API 키 | <https://platform.claude.com/settings/keys> | 내 Claude Console 크레딧 (앱이 추정 비용 집계) |
| GPT (OpenAI) | OpenAI API 키 (`sk-…`) | <https://platform.openai.com/api-keys> | 내 OpenAI Platform 크레딧 (비용 미집계) |
| Gemini | Google AI Studio API 키 | <https://aistudio.google.com/apikey> | 무료 등급 가능 (비용 미집계) |

**초대 코드 (키 없이 쓰기)**
- 처음 열면 **초대 코드 칸 하나**만 있는 첫 화면이 나옵니다. 받은 코드를 넣고 **시작**을 누르면 바로 서재가 열립니다.
  카카오톡으로 받은 **메시지를 통째로 붙여넣어도** 코드만 골라 냅니다. 대소문자와 하이픈(-)은 아무렇게나 써도 됩니다.
- 받은 링크(`https://e2jinsoopark.github.io/#/join/…`)를 열면 코드가 저절로 등록되고 바로 서재가 열립니다.
- 코드가 틀리면 입력칸 아래에 “코드를 찾을 수 없어요”가 나옵니다. 짧은 시간에 여러 번 틀리면 잠시(10분 안) 막힙니다.
- 이미 등록한 뒤에는 **설정 → AI 번역 → 키 없이 쓰기**에서 코드를 바꾸거나 **테스트**할 수 있습니다.

초대 코드로는 초대한 분의 Claude(보통 Haiku, 코드에 따라 Sonnet도)를 쓰며, 하루 사용 한도는 초대한 분이 정하고
한국 시간 0시에 다시 열립니다.
초대받은 분도 원하면 **내 API 키 쓰기**에서 Claude·GPT·Gemini 키를 등록해 직접 연결할 수 있습니다. 이때도 초대 코드는
그대로 저장되어 있어, 맨 위 초대 코드 카드를 누르면 한 번에 돌아옵니다.
(초대 코드 서버를 운영하는 방법: `relay/README.md`, `docs/notes/relay.md`)

**홈 화면에 추가 (휴대폰)**
서재 왼쪽 아래(휴대폰에서는 위쪽)의 **홈 화면에 추가** 버튼을 누릅니다. 앱으로 설치된 상태에서는 버튼이 보이지 않고,
팝업의 **버튼 숨기기**로 감출 수도 있습니다(컴퓨터에서는 브라우저가 설치를 지원할 때만 보입니다).
- 안드로이드(Chrome 등): 브라우저의 설치 창이 바로 뜹니다. 창이 안 뜨면 안내대로 **브라우저 메뉴 ⋮ → 홈 화면에 추가**.
- 아이폰·아이패드(Safari): 버튼을 누른 뒤 **공유 → 홈 화면에 추가**. 아이폰의 홈 화면 앱은 Safari와 저장 공간이 따로라서,
  버튼이 주소창에 초대 코드를 넣어 둡니다(`#/join/<코드>`). 그래서 홈 화면 아이콘으로 열어도 코드를 다시 넣을 필요가
  없습니다. 버튼을 누르지 않고 추가했다면 첫 화면에 코드를 한 번 넣으면 됩니다.
  (아이폰 동작은 실제 기기에서 아직 확인하지 않았습니다 — `docs/notes/onboarding.md` §5)

**Claude**
1. <https://platform.claude.com> 에 로그인 → **API Keys** → **Create Key**
2. 만든 키를 앱의 **설정 → AI 번역 → Claude** 에 붙여넣고 **테스트**를 누릅니다.
3. Claude **Max** 요금제라면 claude.ai **설정 → 결제 → API 크레딧**에서 Console 조직을 연결하면
   요금제에 포함된 API 크레딧(Max 5x: 월 $100 / Max 20x: 월 $200)을 쓸 수 있습니다. 키는 크레딧이 연결된 그 조직에서
   만들어야 합니다. 채팅·Claude Code 사용 한도와는 별개입니다. Pro 요금제는 해당이 없어 Console에서 따로 충전해야 합니다.
4. **테스트**는 키가 유효한지만 확인합니다(크레딧 잔액은 확인하지 않음). 번역할 때 “크레딧이 없거나 부족합니다”가 나오면
   Claude Console의 Billing을 확인하세요.

**GPT (OpenAI)**
1. <https://platform.openai.com/api-keys> 에 로그인 → **Create new secret key**
2. 만든 키(`sk-`로 시작)를 **설정 → AI 번역 → GPT (OpenAI)** 에 붙여넣고 **테스트**를 누릅니다.
3. API 사용료는 ChatGPT 구독(Plus·Pro)과 별개로 OpenAI Platform의 Billing 크레딧에서 나갑니다. 이 앱은 GPT 비용을
   계산하지 않으니(비용 미집계) OpenAI 결제 화면에서 확인하세요.
4. 일부 최신 GPT 모델은 OpenAI **조직 인증**(Settings → Organization → General)을 마쳐야 쓸 수 있습니다. 인증 전에는 앱이
   그 키로 쓸 수 있는 다른 GPT 모델로 바꿔 계속합니다.

**Gemini (무료 등급 가능)**
1. <https://aistudio.google.com/apikey> → **Create API key**
2. 무료 등급은 하루 요청 수 제한이 있고, 입력 내용이 Google 제품 개선에 쓰일 수 있습니다.
   출판된 논문은 괜찮지만 **미출판 원고·민감 자료는 넣지 마세요.**

**모델은 자동으로 고릅니다(‘자동 선택’).** 모델 이름을 직접 넣을 필요가 없습니다.
- 키를 저장하거나 **테스트**하면 그 키로 쓸 수 있는 모델 목록을 회사 서버에서 불러와, 번역에는 빠르고 저렴한 모델
  (Claude Haiku, GPT Luna·mini, Gemini Flash), 요약·채팅·설명에는 더 좋은 모델(Claude Sonnet, GPT Sol, Gemini Flash)을
  최신 버전으로 고릅니다. 설정을 열 때와 초대 코드로 접속할 때마다 목록을 다시 확인해 새 모델을 따라갑니다.
- 새 키로는 쓸 수 없는 이전 세대 모델(예: Gemini 2.x, GPT-4 계열)은 고르지 않고, 목록에도 보여 주지 않습니다.
- 쓰던 모델이 없어지거나 그 키·초대 코드로 쓸 수 없게 되면(“모델을 찾을 수 없음”, 조직 인증 필요, 초대 코드에서 빠진
  모델) 앱이 그 자리에서 같은 키의 다른 모델로 바꿔 요청을 한 번 다시 보내고, “○○ 모델을 쓸 수 없어 △△(으)로
  바꿨습니다.”라고 한 번 알려 줍니다. 쓸 수 없던 모델은 그 키에서 30일 동안 자동 선택에서 빠집니다.
- 원하면 설정에서 모델을 직접 고를 수 있습니다. 직접 고른 모델은 목록에서 사라지거나 쓸 수 없다고 확인될 때만
  ‘자동 선택’으로 돌아갑니다(직접 다시 고르면 다시 시도합니다).

### 2. GitHub 동기화 (선택)

1. 논문을 저장할 **비공개** 저장소를 하나 준비합니다 (예: `paper-library`).
2. <https://github.com/settings/personal-access-tokens/new> 에서 **Fine-grained token** 만들기
   - Resource owner: 저장소를 가진 계정(보통 본인 개인 계정)
   - Repository access: **Only select repositories** → 위 저장소 하나만 선택
   - Permissions → Repository permissions → **Contents: Read and write** (나머지는 건드리지 않음)
   - 만료 기간을 정하고 **Generate token**
3. 앱 **설정 → GitHub 동기화**에 소유자·저장소 이름·토큰을 넣고 **연결 테스트**(성공하면 바로 저장되고 동기화가 시작됩니다).
   이 기기에 다른 저장소의 데이터가 있으면 새 저장소에 올릴지 먼저 묻습니다.

동기화를 켜지 않아도 브라우저 안(IndexedDB)에 저장되어 그 기기에서는 계속 쓸 수 있습니다.

## 공용 서재 (코드별 서재 + 전체 공용 서재)

초대 코드를 받은 사람에게는 서재가 두 개 보입니다.
- **‘<코드 이름> 서재’** (자물쇠 아이콘): **그 초대 코드를 가진 사람만** 봅니다. 다른 코드의 사람에게는 보이지 않습니다.
  같은 코드를 여러 명이 쓰면 그 서재도 함께 씁니다.
- **전체 공용 서재** (사람 아이콘): 초대 코드를 받은 **모두**가 함께 봅니다.

어느 서재든 그 서재를 보는 사람은 똑같은 권한으로 폴더를 만들고·이름을 바꾸고·옮기고·지우며, 논문을 추가·이동·삭제할
수 있습니다. 자세한 구조: [docs/CODE-LIBRARIES.md](docs/CODE-LIBRARIES.md).

| 항목 | 누가 보나 |
|---|---|
| 폴더, 논문(PDF·제목·폴더 위치) | 그 서재를 보는 사람 모두 |
| 번역 | 그 서재를 보는 사람 모두 — 한 사람이 번역한 문장은 다른 사람이 열 때 그대로 보이고, 다시 번역하지 않으므로 비용도 들지 않습니다 |
| 하이라이트·메모 | 나만 — 같은 초대 코드로 다른 PC에서 열면 내 것이 그대로 있습니다 |
| AI 요약·채팅·설명·핵심 밑줄 | 나만 (다른 PC에서도 같은 코드면 그대로) |
| 즐겨찾기·최근 읽음 | 나만 (그 브라우저에만) |

누구나 지울 수 있으므로 안전장치가 있습니다.
- **휴지통**: 지운 폴더·논문은 30일 동안 휴지통에 있고 누구나 **복구**할 수 있습니다. 누가 언제 지웠는지 보입니다.
  논문 파일(PDF)은 관리자가 휴지통을 비울 때까지 남습니다. 지운 직후에는 알림의 **되돌리기**로도 돌아옵니다.
- **최근 활동**: 그 서재에서 누가 무엇을 추가·이동·삭제·번역했는지 이름과 함께 날짜별로 보여 줍니다(다른 서재의 일과
  개인 메모 저장은 나오지 않습니다).
- 팀 저장소의 변경 기록(git)에도 모두 남습니다.

### 초대받은 분(동료)

1. 받은 **초대 링크**를 엽니다. 또는 갈피 첫 화면에 받은 코드(메시지 통째로도 됨)를 넣고 **시작**.
2. **‘<코드 이름> 서재’**가 바로 열립니다(“초대 코드를 등록했어요.” 알림만 잠깐 뜹니다). 그 아래에 **전체 공용 서재**가
   있습니다. 이 브라우저에만 있는 **내 서재**는 쓰기 시작해야 보입니다.
3. 논문 추가: 올릴 서재와 폴더를 고르고 **PDF 추가**(또는 목록에 끌어 놓기). 곧바로 그 서재를 보는 사람에게 보입니다.
   다른 서재로 보내려면 논문·폴더 메뉴(⋯) → **다른 서재로 복사…**(PDF와 번역만 복사).
4. 논문을 열면 위쪽에 “○○ 서재 · 이 코드만 보는 서재” 또는 “전체 공용 서재 · 번역은 모두와 공유, 메모는 나만” 표시가
   있습니다. 이미 번역된 문장은 바로 보이고, 새로 번역한 문장은 그 서재에 저장됩니다. 하이라이트와 메모는 다른 사람에게
   보이지 않습니다.
5. 지울 때는 “휴지통으로 이동합니다. 30일 안에 복구할 수 있습니다”라고 한 번 묻습니다. 실수했다면 **휴지통 → 복구**.
6. 다른 PC에서는 같은 초대 링크를 한 번 더 열거나, 첫 화면에 코드를 넣으면 됩니다. 공용 PC에서 썼다면 **설정 → 이 기기의 데이터 모두 지우기**
   (서버의 공용 서재와 내 메모는 지워지지 않습니다).

### 소유자(관리자)

- **내 서재는 그대로**입니다(내 비공개 GitHub 저장소, 내 토큰). 공용 서재는 따로 만든 비공개 저장소
  `dindoopark/paper-team-library`에 저장되고, 초대 코드 서버가 중계합니다. 그 저장소의 GitHub 토큰은 **서버에만** 있고
  동료의 브라우저로는 가지 않으며, 동료는 초대 코드로만 접근합니다.
- **처음 한 번 — 서버에 공용 서재 켜기**: GitHub 토큰 만들기(그 저장소 하나, Contents 읽기·쓰기) →
  `npx wrangler secret put TEAM_GITHUB_TOKEN` → `npx wrangler d1 execute paper-relay --remote --file schema.sql` →
  `npx wrangler deploy`. 자세한 순서는 `relay/README.md`의 “공용 서재 켜기”에 있습니다. 앱은 고칠 필요가 없습니다.
- **내 기기에서 공용 서재 보기**: 설정 → 초대 코드 관리에서 내 이름으로 초대 코드를 하나 만들고, 그 초대 링크를 내
  브라우저에서 엽니다. 내 서재의 GitHub 동기화는 그대로이고, 왼쪽에 **내 서재**, **‘내 이름 서재’**, **전체 공용 서재**가
  함께 보입니다.
  (초대 링크를 열면 AI 번역이 초대 코드로 바뀝니다. 내 API 키로 번역하려면 설정 → AI 번역에서 다시 고르세요.
  공용 서재는 그대로 보입니다.)
- **다른 서재로 복사**: 논문이나 폴더의 메뉴(⋯ 또는 오른쪽 클릭) → **다른 서재로 복사…** → 서재와 폴더를 고릅니다(그
  자리에서 새 폴더도 만들 수 있음). 다른 서재의 폴더로 끌어 놓아도 됩니다. PDF와 번역만 복사되고, 내 하이라이트·메모·AI
  결과는 복사되지 않습니다. 받는 서재에 이미 같은 PDF가 있으면 다시 올리지 않고 그 논문을 고른 폴더에 넣습니다.
- **동료 초대·내보내기**: 설정 → 초대 코드 관리에서 코드를 만들고 **초대 메시지 복사**로 보냅니다. 메시지는 제목,
  링크, `코드: …` 세 줄입니다. 코드를 **중지**하면 그 사람은 번역뿐 아니라 공용 서재에도 바로 들어올 수 없습니다
  (**다시 사용**으로 되돌린 뒤에는 그 사람이 초대 링크를 한 번 더 엽니다). **삭제**는 되돌릴 수 없습니다: 전체 공용
  서재에 그 코드로 남긴 하이라이트·메모·AI 기록이 지워지고(논문·폴더·번역과 사용 비용 기록은 남음, 목록 아래 "삭제된 코드"
  줄), 그 코드의 서재는 확인 창에서 고른 대로 **서재도 함께 삭제**(기본, 논문 수를 보여 줌)하거나 **다른 코드로 옮기기**로
  고른 코드의 서재에 논문·폴더·번역·메모째 넘깁니다(사람에게 새 코드를 줄 때). 같은 코드를 다시 만들면 새 사람으로
  시작합니다. 삭제된 코드를 쓰던 기기는 다음 요청 때 "초대 코드가 더 이상 쓰이지 않아요. 새 코드를 넣어 주세요."를 보여 줍니다.
- **이미 전체 공용 서재에 올라간 논문 나누기 (한 번)**: 설정 → 초대 코드 관리 → **전체 공용 서재 논문을 올린 사람 서재로
  나누기**. 올린 사람 이름이 코드 하나의 이름과 똑같은 논문을 그 코드의 서재로 옮깁니다(PDF·번역·올린 사람의 메모, 같은
  이름의 폴더째). 먼저 옮길 목록을 보여 주고, **N편 옮기기**를 눌러야 실행합니다. 휴지통의 논문과 이름이 맞는 코드가 없거나
  여럿인 논문은 그대로 두고, 비게 된 폴더는 휴지통으로 갑니다. 서버를 새로 배포한 뒤 앱을 배포하고 실행합니다
  (순서: [docs/CODE-LIBRARIES.md](docs/CODE-LIBRARIES.md) §6).
- **코드 직접 정하기 (맞춤 코드)**: 새 초대 코드의 **코드 직접 정하기** 칸에 원하는 코드를 넣습니다(예: `EICU2-2026`).
  영문·숫자·하이픈 6~24자이며, 대소문자와 하이픈은 구분하지 않습니다(`eicu2 2026`으로 넣어도 같은 코드).
  `PR-XXXX-XXXX` 모양, 예약어(ADMIN, TEST 등), `123456`·`QWERTY` 같은 쉬운 코드, 이미 있는 코드는 쓸 수 없습니다.
  비워 두면 예전처럼 무작위 코드가 만들어집니다. **여러 명이 같은 코드를 쓰면 메모와 사용 한도도 함께 씁니다**
  (공용 서재에서 한 사람으로 취급). 짧은 코드는 추측될 수 있어, 서버는 같은 곳(IP)에서 10분에 20번 넘게 틀리면
  잠시 막습니다. 그동안 그 IP에서는 맞춤 코드도 막히고 자동 코드(`PR-…`)만 들어올 수 있습니다.
- **휴지통 비우기·용량**: 관리자 토큰을 저장한 기기에서 전체 공용 서재 **휴지통 → 30일 지난 항목 비우기**(모든 서재의
  30일 지난 논문의 PDF·번역·메모 파일을 지움), **설정 → 공용 서재 → 용량 확인**. 코드별 서재의 용량(기본 500 MB)은
  초대 코드의 **한도·모델 수정**에서 바꿉니다.
- 모두가 보는 서재를 하나 더 만드는 방법(예: 연구실 서재): `docs/notes/shared.md`.

각 회사 결제 화면에서 확인하세요. 초대 코드 사용량은 초대 코드 서버가 센 오늘 사용액으로 보여 줍니다.

## 보안·개인정보

- 이 사이트의 **코드**는 공개되어 있지만, 올린 **논문·번역·메모**는 내 브라우저와 내 비공개 저장소에만 있습니다.
- **전체 공용 서재**에 올린 논문·번역은 초대 코드를 가진 모든 사람이, **‘<이름> 서재’**에 올린 것은 그 코드를 가진 사람만
  봅니다. 하이라이트·메모·AI 기록도 팀 저장소(비공개)의 내 칸(`people/<내 번호>/`)에 저장되지만, 서버가 다른 사람에게는
  보여 주지 않습니다(저장소 소유자는 GitHub에서 모두 볼 수 있습니다).
- 번역·요약·채팅을 할 때 해당 문장이 선택한 AI 제공자(Anthropic·OpenAI·Google)로 전송됩니다. 초대 코드로 쓸 때는
  초대 코드 서버(Cloudflare)를 거쳐 Anthropic으로 갑니다. GPT 요청은 OpenAI에 저장하지 않도록(`store: false`) 보냅니다.
- 공용 PC에서 썼다면 **설정 → 이 기기의 데이터 모두 지우기**를 누르세요. 키·토큰과 함께 그 브라우저에 남은
  논문·번역·메모·사용 기록을 지웁니다(GitHub 저장소의 데이터는 그대로).
- ‘관련 논문’과 인용 정보는 처음 쓸 때 한 번 동의를 받은 뒤 논문 제목·DOI·참고문헌 문구를 PubMed·Europe PMC·Crossref로 보냅니다(없으면 Semantic Scholar).

### 배포(호스팅) 주의

API 키·GitHub 토큰·논문은 **브라우저의 사이트(origin)별 저장소**(localStorage·IndexedDB)에 있습니다. GitHub Pages의
프로젝트 사이트(`<계정>.github.io/<저장소>/`)는 같은 계정의 **다른 Pages 사이트와 origin을 공유**하므로, 그 사이트들의
스크립트가 이 앱의 키·토큰·논문을 읽을 수 있습니다. 그래서:

- 이 앱만 올리는 **전용 origin**에서 배포하세요. 예: 이 앱 전용 GitHub 계정(조직)의 `<이름>.github.io` 루트 사이트,
  또는 사용자 도메인(CNAME, 예: `papers.example.com`). 같은 origin에 다른 프로젝트 페이지나 service worker를 두지 마세요.
- 앱이 공유 origin(`*.github.io/<프로젝트>/`)에서 열리면 **설정 → 보안·데이터**에 경고가 표시됩니다.
- 배포에는 앱 파일(`index.html`, `manifest.webmanifest`, `css/`, `js/`, `vendor/`, `assets/`)만 올리는 것을 권장합니다(GitHub Actions의 Pages artifact나
  배포 전용 브랜치). `tests/` 페이지가 함께 올라가도 localhost가 아니면 항상 모의 AI로만 동작합니다.

## 한계

- 스캔한 이미지 PDF는 글자 정보가 없어 번역할 수 없습니다 (보기는 가능).
- PDF 한 개는 최대 70 MB까지 추가할 수 있습니다 (GitHub API가 받는 크기 제한 때문).
- 수식이 많은 부분, 표 안의 글자, 아주 복잡한 레이아웃은 문장 구분이 어긋날 수 있습니다.

## 개발

정적 파일만으로 동작합니다(빌드 없음). 로컬 실행:

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000/?mock=1` 을 열면 실제 API를 부르지 않는 가짜 AI로 시험할 수 있습니다.
구조와 모듈 계약은 [docs/SPEC.md](docs/SPEC.md)를 보세요.

전체 흐름 자동 테스트(Edge + Playwright, 가짜 AI·가짜 GitHub): `node tests/e2e/run.mjs` —
준비물과 모듈별 테스트는 [docs/notes/integration.md](docs/notes/integration.md)와 각 `docs/notes/*.md`에 있습니다.
공용 서재를 실제 앱 + 로컬 초대 코드 서버(`wrangler dev`) + 가짜 GitHub·가짜 Anthropic으로 끝까지 시험하는 테스트:
`node tests/shared-e2e/run.mjs` ([docs/notes/shared.md](docs/notes/shared.md)), 코드별 서재·나누기·코드 삭제(옮기기):
`node tests/code-libs/run.mjs` ([docs/CODE-LIBRARIES.md](docs/CODE-LIBRARIES.md)).
첫 화면·맞춤 코드·홈 화면에 추가: `node tests/onboarding/run.mjs`(가짜 서버, Edge + WebKit 아이폰),
`node tests/onboarding/worker-e2e.mjs`(로컬 초대 코드 서버까지) — [docs/notes/onboarding.md](docs/notes/onboarding.md).

포함된 외부 라이브러리: [pdf.js](https://github.com/mozilla/pdf.js) (Apache-2.0),
[marked](https://github.com/markedjs/marked) (MIT), [DOMPurify](https://github.com/cure53/DOMPurify) (Apache-2.0 / MPL-2.0).
각 라이선스는 `vendor/` 폴더에 있습니다.
